2. **Pricing Transparency:** Pricing models classified based on publicly declared USD / EUR / IRR figures. Unlisted enterprise quotes marked as 'Custom / Partner Quote'.
3. **No Fabrication:** Features without direct public API/UI documentation are explicitly flagged NOT_VERIFIED.
