### 1.1 Production & Test Code Changes

- **`backend/src/services/product.service.ts`**: Set `product.quantity = Number(data.quantity) || 0` after opening stock movement is recorded so the returned JSON reflects opening stock immediately (covered by `backend/src/__tests__/parity.test.ts > Parity 1`).
- **`backend/src/routes/invoice.routes.ts`**: Replaced 500 fallback in `fastify.post('/api/invoices')` with `sendFailure(reply, fastify.log, err, 'Failed to create invoice')` so domain validation failures return HTTP 400 instead of 500 (covered by `backend/src/__tests__/parity.test.ts > Parity 4`).
- **`apps/desktop/electron/main/db/__tests__/migrations.test.ts`**: Changed expectation `invoices[0]?.exchange_rate` from `1.0` to `toBeNull()` to match the removal of `DEFAULT 1.0` on SQLite invoice table (covered by `apps/desktop/electron/main/db/__tests__/migrations.test.ts`).

## 4. `better-sqlite3` and `node:sqlite` Resolution (Option c Executed)

As selected by the owner (Option c):

1. **Engine and Parity Test Suites on `node:sqlite`:**
   `packages/local-engine/src/__tests__/test-db.ts` uses Node 22's built-in `node:sqlite` (`DatabaseSync`), adapting directly to `LocalDb`. `backend/src/__tests__/parity.test.ts` connects `LocalDb` via this same in-memory driver. Ambient types are shared from `packages/app-bridge/src/node-sqlite.d.ts`.
2. **Single Version of `better-sqlite3` Across Entire Repository:**
   `better-sqlite3` and `@types/better-sqlite3` were removed from `backend/package.json`, `packages/local-engine/package.json`, root `package.json`, and `pnpm-workspace.yaml`.
   The repository now carries **exactly ONE** `better-sqlite3` version across all `package.json` files:
   `apps/desktop/package.json: "better-sqlite3": "^11.3.0"`.
3. **Zero ABI Conflicts & No Rebuild Dance:**
   The desktop keeps its native Electron-ABI binary (`rebuild:native`), while all Node tests run natively against `node:sqlite`. Neither side steps on the other, and no `NODE_MODULE_VERSION` conflicts can occur.

Gate 4 Rework is **GREEN**.
