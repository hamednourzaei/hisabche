## 6. Findings Resolved Before Phase 3

All five findings noted by the owner were addressed and verified:

1. **Seven local `round2` declarations eliminated:**
   - All copies in `packages/validation/src/schemas/profit-report.domain.ts`, `backend/src/services/accounting/evidence.domain.ts`, `ai/pipeline/pipeline.domain.ts`, `analytics/break-even.domain.ts`, `analytics/cohort.domain.ts`, `crm/crm.domain.ts`, and `financing/working-capital.domain.ts` now import shared `round2` from `packages/validation/src/schemas/money.ts`.
   - `money-primitive-guard.test.ts` updated with both regex forms (`function round2` and `round2 =` / `round2 = (`).
   - Injection tests added and verified (rogue file produces red failure with file name).
   - EPSILON difference tested and characterized: `(1.005 + EPSILON) * 100` yielded 1.01 in the old AI proposal copy, whereas shared `round2(1.005)` yields 1 (consistent with IEEE-754 and invoice totals).
   - Comment in `profit-report.domain.ts` mentioning hiding from guard was removed.
2. **`invoice.service.ts` Rule 3 violation fixed:**
   - `buildItemRows` now derives `total_price` using `computeItemTotalRounded(...)` with currency, never trusting client `item.totalPrice`.
   - `applyCosting` derives `lineTotal` using `computeItemTotalRounded(...)` instead of `item.totalPrice || ...`.
   - `postToLedger` and `postApprovedInvoice` recompute line totals via `computeItemTotalRounded(...)`.
   - `invoice-derived-money.test.ts` added 5 new tests covering two currencies (AFN and USD) where client sends wrong `totalPrice` and server derives the correct line and invoice totals, source assertions, and injection tests.
3. **Decisions on names applied:**
   - `round2`: remains one function; unknown values remain null (unknown ≠ zero).
   - `PeriodLock` → `LedgerPeriodLock` permanent name.
   - `stockValue` → `layersValue` (cost layers), `stockValueAtBuyPrice` (warehouse map / inventory), `stockValueAtSellPrice` (selling price).
   - `grossProfit`: financial line/total rule in profit-report and costing remains `grossProfit`; period metric in `insights.domain.ts` renamed to `periodGrossProfit`.
   - Guarded by `packages/ui/src/__tests__/one-rule-each.test.ts` (71 passed tests).
