### 2.2 Re-run Idempotency (Running Migrations Twice)

- Test seeds a realistic v2 database with floating-point prices and balances.
- Migration run 1 upgrades schema to v3 and converts amounts (e.g., product buy_price `15.5` → `1550`, invoice total `245.0` → `24500`).
- Migration run 2 restarts database and re-runs `runMigrations(db)`.
- Asserted: amounts are NOT scaled a second time (marker in `meta` protects against double-conversion). Zero rows lost or altered.
