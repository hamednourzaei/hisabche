# چک‌لیست دستی تست دستگاه — نسخه‌ی محلی (Test A + Test B)

> نسخه‌ی محلی (Offline Edition) — فاز ۶ (اجرای اول) و فاز ۵ (جدایی از شبکه).
> تاریخ: ۲۰ اکتبر ۲۰۲۶ · برای مالک.
>
> **دو چیز جدا را می‌سنجیم و هر دو لازم‌اند:**
>
> - **Test A — «کار کرد بدون اینترنت»**: برنامه روی نصب تازه، بدون هیچ شبکه‌ای، کسب‌وکار را می‌سازد و به داشبورد می‌رسد.
> - **Test B — «اصلاً تلاش نکرد به اینترنت وصل شود»**: لاگ شبکه‌ی برنامه + دیواره‌ی آتش.
>
> «کار کرد بدون اینترنت» و «تلاش نکردن» دو واقعیت متفاوت‌اند. اولی با خرابیِ شبکه هم ممکن است (و پس از آن داده‌ها خراب می‌شوند)؛ دومی یعنی برنامه اصلاً بیرون نرفت.

---

## ۱) ویندوز

### ۱.۱ نصب

| مورد                | مسیر                                                                                                                            |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| فایل نصب            | `apps\desktop\dist\Hisabche-0.0.1-setup.exe`                                                                                    |
| مسیر نصب (per-user) | `%LOCALAPPDATA%\Programs\Hisabche\Hisabche.exe` — یعنی `C:\Users\<نام‌کاربری‌شما>\AppData\Local\Programs\Hisabche\Hisabche.exe` |
| مسیر داده‌ی برنامه  | `%APPDATA%\@hisabche\desktop\` — یعنی `C:\Users\<نام‌کاربری‌شما>\AppData\Roaming\@hisabche\desktop\`                            |
| **مسیر لاگ شبکه**   | `C:\Users\<نام‌کاربری‌شما>\AppData\Roaming\@hisabche\desktop\logs\network-offline.log`                                          |

۱. برنامه را کامل ببندید (اگر باز است، از نوار وظیفه خارج کنید).
۲. `Hisabche-0.0.1-setup.exe` را دوبار کلیک کنید و نصب را کامل کنید.
۳. **برای تست تازه‌نصب، پوشه‌ی داده را پاک کنید** (این همان «نصب تازه» است):

```powershell
Remove-Item -Recurse -Force "$env:APPDATA\@hisabche\desktop" -ErrorAction SilentlyContinue
```

۴. برنامه را باز کنید.

### ۱.۲ دیواره‌ی آتش (این را **خودتان** اضافه می‌کنید)

> **PowerShell را «Run as administrator» باز کنید.** این قانون فقط برنامه را قطع می‌کند؛ سیستم و اینترنت شما سالم می‌ماند.

```powershell
$exe = "$env:LOCALAPPDATA\Programs\Hisabche\Hisabche.exe"

# ۱) قطع همه‌ی ترافیک خروجیِ خودِ برنامه
New-NetFirewallRule -DisplayName "Hisabche (offline test)" `
  -Direction Outbound -Program $exe -Action Block -Profile Any

# ۲) (اختیاری ولی توصیه‌شده) قطع DNS برای کل دستگاه، تا هیچ برنامه‌ای
#    نامی را resolve نکند. روی ویندوز درخواست DNS را «سرویس DNS Client»
#    می‌فرستد، نه خودِ برنامه — پس قانون بالا به‌تنهایی DNS را قطع نمی‌کند.
New-NetFirewallRule -DisplayName "Block DNS (offline test)" `
  -Direction Outbound -Protocol UDP -RemotePort 53 -Action Block -Profile Any
```

**بعد از تست، هر دو را بردارید:**

```powershell
Remove-NetFirewallRule -DisplayName "Hisabche (offline test)"
Remove-NetFirewallRule -DisplayName "Block DNS (offline test)"
```

### ۱.۳ Test A — اجرای اول روی نصب تازه (شماره‌گذاری‌شده)

| #   | کار                                                                   | چه چیزی باید ببینید                                                                            |
| --- | --------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| A1  | صفحه‌ی ورود باز می‌شود                                                | همان صفحه‌ی همیشگی (ایمیل/رمز) و پایینش لینک **«نسخه‌ی محلی (بدون اینترنت)»**                  |
| A2  | روی **«نسخه‌ی محلی (بدون اینترنت)»** کلیک کنید                        | فرم **«کسب‌وکار خود را بسازید»** باز می‌شود: یک کادر «نام کسب‌وکار» و یک انتخاب‌گر «ارز دفاتر» |
| A3  | دقت کنید که انتخاب‌گر ارز **هیچ گزینه‌ای از پیش انتخاب‌شده ندارد**    | هیچ ارزی از قبل تیک نخورده باشد. (اگر تیک خورده بود، یعنی نسخه‌ی قدیمی نصب شده)                |
| A4  | نام کسب‌وکار را تایپ کنید (مثلاً «دوکان تست») و یک ارز را انتخاب کنید | دکمه‌ی «ساخت کسب‌وکار و شروع» فعال می‌شود                                                      |
| A5  | دکمه را بزنید                                                         | **داشبورد** باز می‌شود. هیچ پیام خطایی نباید باشد                                              |
| A6  | در داشبورد، «ارز دفاتر» را ببینید                                     | همان ارزی که انتخاب کردید (نه AFN)                                                             |
| A7  | برنامه را **کامل ببندید** و دوباره باز کنید                           | مستقیم **داشبورد** — فرم «ساخت کسب‌وکار» دیگر نمی‌آید و چیزی پرسیده نمی‌شود                    |
| A8  | یک مشتری بسازید، یک کالا با موجودی اولیه، یک فاکتور فروش، یک پرداخت   | اعداد درست‌اند و هیچ خطایی نیست                                                                |
| A9  | یک فاکتور را چاپ کنید (Print)                                         | چاپ بدون خطا                                                                                   |
| A10 | از تنظیمات، **Export / پشتیبان** بگیرید                               | فایل ذخیره می‌شود (JSON یا xlsx)                                                               |
| A11 | کل پنجره را در حالی که دیواره‌ی آتش فعال است ببندید و باز کنید        | باز هم کار می‌کند (A5 تا A10 بدون اینترنت)                                                     |

### ۱.۴ Test B — لاگ شبکه (همان‌وقت که Test A را اجرا می‌کنید)

۱. بعد از **A5** (ساخت کسب‌وکار) فایل لاگ را باز کنید:

```powershell
notepad "$env:APPDATA\@hisabche\desktop\logs\network-offline.log"
```

۲. **شکل لاگ:**

| خط          | معنی                                                                                                                                                       |
| ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| خط ۱        | `# hisabche network log — started 2026-10-20T…Z` — زمان شروع اجرا                                                                                          |
| خط ۲ به بعد | **یک تلاش برای خروج از دستگاه**، با زمان و منبع: `[webRequest]` (ترافیک مرورگر)، `[dns]`، `[http]`، `[https]`، `[net]`، `[fetch]` (ترافیک خودِ پروسس اصلی) |

۳. **معیار قبولی Test B: فایل باید فقط یک خط داشته باشد** (همان خط شروع). اگر خط دومی هست، یعنی برنامه واقعاً به اینترنت نگاه کرده — همان خط را برای من بفرستید.
۴. **اگر لاگ وجود نداشت:** یعنی نسخه‌ی نصب‌شده قدیمی است (لاگ در نسخه‌ی ساخته‌شده‌ی امروز اضافه شده). نصب را دوباره انجام دهید.
۵. برای دیدن مسیر دقیق در PowerShell:

```powershell
Get-ChildItem "$env:APPDATA\@hisabche\desktop\logs"
```

## ۲) اندروید

### ۲.۱ نصب

```powershell
adb install -r apps\mobile\android\app\build\outputs\apk\release\app-release.apk
# یا: adb uninstall com.hisabche.mobile  &&  adb install <مسیر apk>
```

نام بسته: `com.hisabche.mobile` · نسخه: `0.0.1` (versionCode 1).

### ۲.۲ حالت هواپیما را روشن کنید و **اثباتش** را بگیرید

```powershell
adb shell settings get global airplane_mode_on        # باید 1 باشد
adb shell dumpsys connectivity | Select-String -Pattern "Active default network"   # باید چیزی نیاید
```

(روی خود گوشی هم حالت هواپیما را روشن کنید؛ `adb shell cmd connectivity airplane-mode enable` هم همان کار را می‌کند.)

### ۲.۳ Test A — اجرای اول روی نصب تازه (شماره‌گذاری‌شده)

| --- | ------------------------------------------------------------ | ---------------------------------------------- |

### ۲.۴ Test B — netstats قبل و بعد (دقیق)

```powershell
# ۱) قبل از باز کردن برنامه
adb shell dumpsys netstats > netstats-before.txt

# ۲) برنامه را باز کنید و M1 تا M7 را انجام دهید، بعد ببندید

# ۳) بعد از تست
adb shell dumpsys netstats > netstats-after.txt

# ۴) UID خودِ برنامه را پیدا کنید
adb shell dumpsys package com.hisabche.mobile | Select-String -Pattern "userId="

# ۵) فقط همان UID را در هر دو فایل مقایسه کنید
#    (عدد بایت‌ها و پکت‌های همان UID باید یکی باشد)
Select-String -Path netstats-before.txt -Pattern "uid=10234" -Context 0,12   # UID را از مرحله‌ی ۴ بگذارید
Select-String -Path netstats-after.txt  -Pattern "uid=10234" -Context 0,12
```

**معیار قبولی:** شمارنده‌ی بایت/پکتِ UID برنامه در `after` **با `before` یکی باشد** (یعنی صفر). اگر فرق کرد، یعنی برنامه از شبکه رد داده.

### ۲.۵ لاگ دستگاه

```powershell
adb logcat -d > device-log.txt                 # کل لاگ دستگاه
adb logcat -d | Select-String -Pattern "hisabche|chromium|ReactNativeJS" | Select-Object -Last 200
```

### ۲.۶ آنچه روی اندروید فرق دارد (صادقانه)

روی اندروید **فایل لاگ شبکه‌ی اختصاصی وجود ندارد** (آن فایل مخصوص پروسس اصلی Electron است، §۱.۴). مدرک اندروید سه چیز است: **حالت هواپیما (۲.۲)** + **شمارنده‌ی UID در netstats (۲.۴)** + **لاگ دستگاه (۲.۵)**.

## ۳) چه چیزی را برای من بفرستید

1. نتیجه‌ی هر شماره‌ی A1…A11 و M1…M7 (قبول / خطا + متن خطا).
2. **فایل لاگ ویندوز** (اگر بیش از یک خط داشت): `C:\Users\<you>\AppData\Roaming\@hisabche\desktop\logs\network-offline.log`
3. خروجی `netstats-before.txt` و `netstats-after.txt` (یا فقط بخش UID برنامه).
4. اگر جایی گیر کرد: همان متن خطا، دقیقاً همان‌طور که در برنامه دیده می‌شود.

> یک نکته برای دقت: «کار نکردن» را با «کار کردن ولی با داده‌ی خراب» اشتباه نگیرید. اگر چیزی در عددها غلط است (مثلاً ارز دفاتر)، همان‌جا علامت بزنید — شماره‌ی غلط بدتر از خطای آشکار است.
