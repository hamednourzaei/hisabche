## 1. Summary of Delivered Work

In Phase 5, the local business engine (`@hisabche/local-engine`) has been fully integrated across desktop (Windows Electron) and mobile (Android Expo React Native) hosts, and wired into the client HTTP transport layer (`@hisabche/api`).

### A. Core Transport & API Layer (`@hisabche/api`)

- **Edition Management**: Added `setAppEdition(edition: 'offline' | 'cloud')` and `getAppEdition(): 'offline' | 'cloud'`, persisted under `STORAGE_KEYS.edition`.
- **Offline Token Mode**: Added `setOfflineTokenMode(offline: boolean)` and `isOfflineTokenMode()`. When offline, token acquisition settles immediately with a local offline dummy token, avoiding infinite auth waiting loops.
- **Local Transport Routing**: Added `registerLocalTransport(adapter)` in `packages/api/src/lib/client.ts`. When `getAppEdition() === 'offline'`, client HTTP requests are intercepted and dispatched to the local engine adapter with all path parameters, query parameters, idempotency keys, language headers, and tenant context.
- **Error Normalization**: Non-2xx local engine responses are translated into standard `AxiosError` producing exact `ApiError` instances conforming to `apiErrorMessage` and `apiErrorFields`.
- **Query Cache Persistence**: Guarded `packages/api/src/lib/persisted-query-cache.ts` so cache persistence and restoration are bypassed when running in offline edition.

### B. Bridge Protocol (`@hisabche/app-bridge`)

- **IPC & Contract**: Added `IPC.localApiRequest = 'local-api:request'`, `localEngineRequestSchema`, and types `LocalEngineRequest`, `LocalEngineResponse`.
- **WebView RPC**: Added `localApiRpcRequestSchema` for `{ type: 'local-api', id, request }` messages.
- **WebView Client**: Injected `window.localApi = { request: (req) => ... }` inside the WebView script before content load, resolving through promise map.

### C. Desktop Platform (`apps/desktop`)

- **Host Engine**: Added `apps/desktop/electron/main/services/local-api.ts` instantiating `createLocalEngine(getLocalDb())`.
- **IPC Handler**: Registered IPC handler in `electron/main/ipc/register.ts` answering `IPC.localApiRequest`.
- **Preload Bridge**: Exposed `window.localApi` in `electron/preload/index.ts` alongside `window.hisabche`.
- **Bundler Guard**: Updated `electron.vite.config.ts` to bundle `@hisabche/local-engine` (passing `packaged-build-has-no-external-workspace.test.ts`).

### D. Mobile Platform (`apps/mobile`)

- **Host Engine Adapter**: Created `apps/mobile/src/host/local-api.ts` implementing `LocalDb` synchronously over `expo-sqlite` (`openDatabaseSync('hisabche.db')`), running schema migrations on init, and exposing `handleMobileLocalApiRequest`.
- **Native Bridge Dispatcher**: Exported `handleLocalApiBridgeCall` in `apps/mobile/src/host/native-bridge.ts`.
- **WebView Receiver**: Updated `ShellWebView.onMessage` in `apps/mobile/src/host/shell-webview.tsx` to handle `local-api` RPC requests and answer via `window.__hisabcheReceive`.

### E. App Shell Integration & Sync Protection (`packages/app-shell`, `packages/sync`)

- **Bridge Accessor**: Declared `window.localApi` and exported `localApi()`, `hasLocalApi()` in `packages/app-shell/src/shared/lib/bridge.ts`.
- **Providers Wire-up**: In `packages/app-shell/src/app/providers.tsx`, auto-registers local transport adapter when `localApi()` exists and activates offline mode if configured.
- **Sync & Stream Bypass**:
  - `packages/sync/src/stream-client.ts`: Returns no-op stream handle when `offline` is specified.
  - `packages/app-shell/src/features/sync/sync-engine.ts`: Bypasses `runSync`, `pullAll`, and `startSyncStream` when in offline mode.
  - `packages/app-shell/src/features/sync/use-sync.ts`: Disabled sync queue polling, background sync intervals, and workspace cache purge in offline mode.
