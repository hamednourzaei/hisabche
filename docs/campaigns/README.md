# کمپین تکمیل اصناف — فهرست و روش اجرا

این پوشه پاسخ یک سؤال است: **برای رساندن هر صنف حسابچه به محصول قابل فروش، دقیقاً چه کاری روی
کدام موتور لازم است — و چطور ثابت می‌کنیم انجام شده؟**

پاسخ به‌صورت ۲۷ «بسته‌ی کاری» روی ۲۱ موتور مشترک نوشته شده، نه ۶۷ موتور موازی.

## ۲. بازتولید اعداد

```bash

node scripts/industry/campaign-status.mjs
```

زنجیره‌ی بالادست (اگر رجیستری عوض شد، اول این‌ها):

## ۴. آنچه این پوشه اثبات نمی‌کند

1. **اعداد از فایل‌های موجود خوانده می‌شوند، نه از اجرای مجموعه‌ی کامل.** در این دور فقط تست‌های رجیستری و پروفایل (`packages/validation`، ۴ فایل / ۶۶ تست) اجرا شد.
2. **هیچ شاهد PostgreSQL یا مرورگری** در این دور ساخته نشد؛ علت: PostgreSQL محلی نصب نیست.
3. **تغییر این دور** رجیستری و مدل نیازمندی است (`business-capabilities.ts`, `industry-profiles.ts`)
   به‌همراه مولدها و تست‌هایشان؛ هیچ مهاجرت، سرویس یا صفحه‌ی محصولی تغییر نکرد.
4. «لنگر کد سالم» یعنی فایل و نماد وجود دارند، نه اینکه گردش کاربر کامل است.
5. اعداد صنوف از رجیستری می‌آیند. ستون نیازمندی اکنون وجود دارد، ولی ۴ صنف هیچ نیازمندی
   ثبت‌شده‌ای ندارند و در شمارش «صنوف نیازمند» دیده نمی‌شوند.
