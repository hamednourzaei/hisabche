«فاز تمام شد» یعنی **دروازهٔ شاهد آن فاز عبور شد**، نه اینکه کدی نوشته شد. شاهد عبارت است از:
خروجی فرمان با کد ۰ · `*.pg.test.ts` که روی PostgreSQL واقعی بنویسد · تست HTTP با `buildServer()`

- `app.inject` · journey مرورگر روی **درخت commitشدهٔ تمیز**. تست واحد سبز بهتنهایی شاهد نیست.

## موانع سخت (غیرقابل رفع توسط عامل)

1. **PostgreSQL زنده.** `postgres.exe` بهدلیل نبودن `SeCreateGlobalPrivilege` بالا نمیآید
   (`FATAL: could not create shared memory segment: error code 1314`). توکن ادمین هم ممنوع است
   (`Execution of PostgreSQL by a user with administrative permissions is not permitted`).
   رفع: `secpol.msc` → Create global objects → sign out/in → ترمینال غیرمدیر.
2. **عدم commit.** `AGENTS.md` قاعده ۰، commit/push ممنوع است. C5 صریحاً «درخت تمیز commitشده» میخواهد.
3. **درخت کثیف.** ۱۶۸ فایل تغییریافته در working tree — حتی با commit مجاز، شاهد فعلی معتبر نیست.
4. **مشتری واقعی (C6).** خارج از دسترس عامل نرمافزاری.
5. **CI (C7).** نیاز به محیط CI/دستیاری مالک.

## آنچه در دسترس عامل است (C0–C4)

پیادهسازی لایههای کد (domain، validation، migration + VERIFY + pg.test بهعنوان فایل، service،
route، Local Engine، hook، UI، سه زبان، گارد) و بازتولید اسناد. شاهد اجرای pg.test منوط به رفع
مانع ۱ است؛ تا آن لحظه وضعیت بستهها `IMPLEMENTED_NOT_LIVE_VERIFIED` میماند.
