# Hisabche universal core — repository inventory

Written 2026-10-26 from the working tree (HEAD `41031ed2` plus uncommitted work). Every path below was opened or searched in this round. **Status vocabulary** (stricter than "exists"):

| Status        | Meaning                                                                                                                                               |
| ------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| `TEST-BACKED` | Implementation traced **and** a test file for it exists. Whether it passes is recorded in `docs/architecture/industry/VERIFICATION-LOG.md`, not here. |
| `IMPLEMENTED` | Implementation traced; no dedicated test found.                                                                                                       |
| `PARTIAL`     | Works for part of the need or one platform; the gap is named.                                                                                         |
| `ABSENT`      | Searched for and not found. The search is stated.                                                                                                     |

Chain used for every row: `UI → shared validation/domain → API or local engine → persistence → financial/stock effect → report → sync`.
