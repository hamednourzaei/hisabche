## ساخته نشد — به ترتیب پیشنهادی (هر کدام: migration + سرویس + route + UI سه پلتفرم + سه زبان + تست)

1. **ظرفیت کلاس و فهرست انتظار** (آموزشگاه) — `resource-capacity-01` برای منبع هست؛ ظرفیت چندنفره و صف انتظار نیست.
2. **کمیسیون قاعده‌محور** (سالن) — امروز یک نرخ ثابت به‌ازای متخصص.
3. **رستوران: میز و سفارش آشپزخانه** — هیچ موجودیتی نیست؛ بزرگ‌ترین شکاف خانواده‌ی غذا.
4. **مواد مصرفی هر خدمت (recipe خدمت)** — سالن و کلینیک.
5. **حمل‌ونقل: مأموریت، راننده، تسویه‌ی بار** — هیچ موجودیتی نیست.
6. **پروژه: بودجه و صورت‌وضعیت** — `cost_center` هست، صورت‌وضعیت نیست.
7. **تولید: WIP و سربار در دفتر کل** — تصمیم مالک لازم است (CLAUDE.md: «تولید سند دفتر کل نمی‌زند»).
8. **کلینیک: داده‌ی حساس جدا با مجوز جدا** — طراحی امنیتی لازم است.
9. **املاک (`realEstate`)** — صنف در رجیستری هست؛ قرارداد، کمیسیون معامله و پرداخت دوره‌ای اجاره به‌عنوان موجودیت ساخته نشده‌اند.
10. **parity دو ذخیره‌ساز روی Postgres (V70.4)، تاب‌آوری sync (V70.5)، دروازه‌ی پک (V70.7)**.
