# Evidence trail — industry personalisation

Every row is a claim, the repository evidence behind it, and the experiment that checked it.
No external source was needed: the contract for every decision below already exists in the
repository and was read directly. Internet research was not used for this change.

| Question                                                    | Repository evidence                                                                                                                            | Experiment                                                   | Result                                                                                        | Decision                                                                                                                          |
| ----------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------ | --------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| Is a profile already persisted anywhere?                    | `profiles.business_types text[] NOT NULL`; backend `PATCH /api/auth/profile` maps `businessTypes`; `auth-core` `User.businessTypes?: string[]` | read route + service + type                                  | Persisted once, no profile field                                                              | Derive the profile in `industry-profiles.ts`; add no column                                                                       |
| Did onboarding save the answer?                             | `onboarding-container.tsx` read `updateProfile` but `handleComplete` only called `completeOnboarding()`                                        | read before/after                                            | Answer stayed local; server value empty                                                       | `handleComplete` now awaits `updateProfile({ onboardingCompleted, businessTypes, storeSize, businessNote })` and stops on failure |
| Which industry is primary when several are selected?        | `business_types` is an array; no ordering contract exists                                                                                      | resolver tests with reversed input, duplicates, comma string | Array insertion order was never stored meaningfully                                           | Registry order; explicit primary wins; documented in ADR-001                                                                      |
| Can a profile claim a capability the product lacks?         | `business-capabilities.ts` makes evidence part of the type; `industry-profiles.test` checks every `available` path exists                      | tests + `existsSync`                                         | Three capabilities have real sources and tests: `measurement`, `weight_pricing`, `multi_unit` | All others `planned`, attached to no profile                                                                                      |
| Is the 15-gram necklace really one gram today?              | `rowQuantity` returned `1` for an empty quantity; `setRowProduct` seeded `1` for every unit                                                    | `measurement.test.ts` regression, red before the fix         | Empty measured line totalled 33,000,000 instead of 0                                          | Counted units seed `1`; measured units seed empty and total `0`; 15 g × 33,000,000 = 495,000,000                                  |
| Are pieces and grams interchangeable?                       | `units-seed.ts` defines conversion factors per dimension; no gram↔piece factor                                                                 | `lineUnitIssue` tests                                        | Conversion exists only inside one dimension                                                   | kg↔gram allowed; gram sold as piece is `unitMismatch`                                                                             |
| Does the unit dropdown expose what the schema accepts?      | `unitSchema` has 16 non-custom units; `UNIT_CHOICES` listed 8                                                                                  | test asserts `ton`, `mg`, `cm` present and `custom` absent   | Missing units were coerced to piece                                                           | `UNIT_CHOICES = INVOICE_UNIT_CHOICES`                                                                                             |
| Is the onboarding label list the same list as the registry? | labels in `@hisabche/ui-contract`, keys in `@hisabche/validation`; no dependency edge                                                          | parity test                                                  | Separate packages can drift                                                                   | Parity test compares both lists and ids                                                                                           |
| Is the dashboard order safe to reorder by industry?         | `dashboard-container.tsx` reads user `pageLook` preferences and `look.shows(...)`                                                              | read container + customizer                                  | Industry ordering would fight a saved user preference                                         | Registry order exists, but the container is not reordered; recorded in OPEN-QUESTIONS                                             |
