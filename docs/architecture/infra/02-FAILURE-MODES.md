# 02 — Failure Modes & Effects Analysis (FMEA)

| Failure Mode                                                         | Detection                                                          | Automatic Response                                                                                                                | Operator Runbook                                              |
| -------------------------------------------------------------------- | ------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------- |
| **Primary DB unreachable or read-only**                              | `/ready` probe fails; write RPC returns connection/read-only error | `serviceMode` transitions to `read_only`; mutating HTTP verbs return `503 SERVICE_READ_ONLY`; reads continue if replica available | [read-only-mode.md](../../runbooks/read-only-mode.md)         |
| **Read Replica lag spikes (`> REPLICA_MAX_LAG_MS`)**                 | Lag check in `db/routing.ts`                                       | `serviceMode` transitions to `degraded`; analytical reads transparently route to `primary`                                        | [failover-drill.md](../../runbooks/failover-drill.md)         |
| **Event loop lag (`> 250ms`) or Heap/RSS spike**                     | `pressureMonitor.snapshot()` in `onRequest`                        | API sheds non-essential traffic with `503 SERVICE_OVERLOADED` + `Retry-After` header                                              | [incident-template.md](../../runbooks/incident-template.md)   |
| **Downstream external API stalls (SMS / Payment Gateway / Webhook)** | `breaker.ts` + per-request `AbortController` timeout               | Circuit breaker opens after threshold failures; fails fast without exhausting Node event loop or DB pool                          | [incident-template.md](../../runbooks/incident-template.md)   |
| **Redis unavailable**                                                | Connection error or missing `REDIS_URL`                            | Falls back to in-memory bounded cache and Postgres rate-limit/job tables (`ADR-0003`)                                             | —                                                             |
| **Region outage (Primary cloud region)**                             | External uptime monitor + health checks fail across AZs            | Trigger backup restore / DNS cutover in secondary region                                                                          | [region-loss.md](../../runbooks/region-loss.md)               |
| **Logical data corruption / bad migration**                          | Application error spike or audit discrepancy                       | Restore latest PITR snapshot to isolated sandbox, verify, then plan forward-fix                                                   | [restore-to-sandbox.md](../../runbooks/restore-to-sandbox.md) |
