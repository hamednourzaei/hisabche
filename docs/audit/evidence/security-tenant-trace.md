## 4. Notifications — `PATCH /api/v1/notifications/mark-read`

`notification.routes.ts:79-98` (`[authenticate]` only) passes the raw `ids` to `NotificationService.markAsRead` (`:99-130`) which reads the rows' `user_id` for logging and then `UPDATE … WHERE id IN (ids)` with **no `user_id` filter**; the route then purges `notifications:*` for everyone. Any authenticated user can mark any notification id read. Severity P3 (read flag only). Negative test: user B marks user A's notification → unchanged.
