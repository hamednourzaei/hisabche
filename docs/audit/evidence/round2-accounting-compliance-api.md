## Reading

- Large vendors and the better-known SMB cloud products publish independent attestations (SOC 2 and/or ISO 27001). Hisabche has none; its documents under `docs/security/` are drafts (see the audit).
- Several certificate PDFs returned by search show an expiry date before 2026-10-26 (Workday copy, Exact copy). That is evidence of an old file in search results, not of lapsed certification.
- Webhook support is documented for QuickBooks, Xero, Zoho, Acumatica; not found for NetSuite, Intacct, BC, SAP in these results.
