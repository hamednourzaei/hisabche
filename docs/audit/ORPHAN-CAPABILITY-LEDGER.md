# Orphan capability ledger

Audit date: 2026-10-26 · All lists are produced by scripts in `scripts/audit/` (reproducible: `node scripts/audit/inventory.mjs`, `node scripts/audit-unwired-routes.mjs`, `node scripts/audit/tenancy-scan.mjs`). Heuristics are named in each section; a hit is a **candidate**, not a verdict.

Reading rule: "orphan" means _no production file other than the definition mentions the name_. A name used only by tests, or only through string-built access, would be wrongly listed; a name used only by dead UI would be wrongly cleared.
