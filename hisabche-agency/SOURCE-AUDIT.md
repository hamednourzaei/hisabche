## 3. Critical Source Defects & Policy Conflicts Found by Audit

1. **Stack & Script Hallucinations in QA/Orchestrator Prompts:**
   - `testing/testing-evidence-collector.md`, `testing/testing-reality-checker.md`, and `specialized/agents-orchestrator.md` hardcode **Laravel / Blade (`resources/views/`, `*.blade.php`, `Filament`)** and non-existent `./qa-playwright-capture.sh http://localhost:8000` commands.
2. **Incompatible Offline Sync & Conflict Models:**
   - `engineering/engineering-realtime-collaboration-engineer.md` prescribes **Last-Write-Wins (LWW)** and **Redis pub/sub** (`await redis.set(...)`, `await redis.publish(...)`) — direct violation of Hisabche's rule banning Redis/polling in sync and forbidding LWW for financial/stock records.
   - `engineering/engineering-backend-architect.md` suggests ad-hoc Redis caching without Hisabche's mandatory `invalidateMoneyCaches(workspaceId)` and non-cachable error isolation.
3. **Mobile Framework Drift Risk:**
   - `engineering/engineering-mobile-app-builder.md` contains SwiftUI/Kotlin/Flutter sections that conflict with Hisabche's frozen **Expo SDK 51 + React Native 0.74 + Legacy WebView (`app-shell`) without New Architecture**.
4. **Encoding Corruption (Mojibake) in Upstream Headings:**
   - Verified raw broken headings (e.g., `## >à`, `## <¯`, `## =¨`, `## =Ë`, `## =ñ`) inside `engineering-mobile-app-builder.md`, `testing-performance-benchmarker.md`, `testing-api-tester.md`, `product-manager.md`, `design-ui-designer.md`, `testing-evidence-collector.md`, and `agents-orchestrator.md`. Normalized cleanly to valid ASCII/UTF-8 Markdown during specialization.
5. **Over-Permissive Tool Metadata:**
   - 25 of 26 selected upstream agents lack explicit `tools:` restrictions (and `product-manager.md` includes `Write, Edit`). Our specialized versions apply least-privilege separation between `read-only` auditors/reviewers and scoped `implementer` specialists, and explicitly inject Hisabche's `AGENTS.md` safety rules.
6. **Harness Compatibility Gaps on Host:**
   - OpenAI Codex CLI (`codex`) is **not installed** on this workstation (`NOT_FOUND`, `~/.codex` absent), while Antigravity (`agy` v-installed, `localhost:53814` LS active) and Claude Code (`claude`, `~/.claude/agents/`) are live. Raw `scripts/install.sh` would blindly overwrite naming conventions or install unfiltered agents; therefore we generate customized versions first via `hisabche-agency/scripts/build-and-sync-agency.mjs` while keeping `C:\Users\hamed\.cache\agency-agents` untouched.
