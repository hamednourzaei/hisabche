## ۲. دیتابیس — دیگر دست نزن، انجام شده

**۳۲ migration اجرا شد** از طریق **SQL Editor**، نه اسکریپت.

### چرا SQL Editor و نه `run-migrations.mjs --apply`

پلن رایگان Supabase: هاست مستقیم (`db.<ref>.supabase.co`) **فقط IPv6** دارد.
شبکه‌ی کاربر IPv6 ندارد → `ENOTFOUND`. با pooler هم پورت ۵۴۳۲ توسط ISP بسته
است → `ETIMEDOUT`.

⚠️ `$env:ALL_PROXY` **هیچ اثری ندارد** — `node-postgres` سوکت TCP خام باز
می‌کند و آن متغیر را نمی‌خواند. وقت تلف نکن.

**راه درست:** `node scripts/bundle-migrations.mjs` → `docs/_bundle.sql` را در
SQL Editor پیست کن. مرورگر از HTTPS/443 می‌رود.

### وضعیت اثبات‌شده‌ی دیتابیس

## ۵. UI — قواعدی که باید رعایت شود

### فقط از کامپوننت‌های `packages/ui` استفاده کن

`capability-kit.tsx` **یک آداپتور نازک است، نه سیستم طراحی**. نسخه‌ی اول
`Panel`/`ActionButton`/`Badge`/`inputClass` مستقل ساخته بود — یعنی هشت صفحه از
بقیه‌ی محصول جدا افتاده بودند. حالا روی `Card`، `Button`، `Badge`، `Input`،
`Select`، `Table`، `Skeleton` سوار است.

آنچه در kit مانده فقط چیزی است که واقعاً مخصوص این صفحه‌هاست: پول در واحد
صحیح، مدت در دقیقه، و ترجمه‌ی tone به variant.

⚠️ **`max-h-[60vh]` به‌عنوان کلاس کار نمی‌کند.** Tailwind کلاس‌های
arbitrary-value را با اسکن سورس تولید می‌کند و `packages/ui` در content glob
اپ وب **نیست**. کلاس در markup می‌آید و هیچ قاعده‌ای برایش وجود ندارد →
`max-height: none`. **از inline style استفاده کن.** (در مرورگر تأیید شد:
پنل ۵۲۹px از پایین صفحه بیرون می‌زد.)

⚠️ **radix `SelectItem` با مقدار خالی را رد می‌کند.** گزینه‌ی
`<option value="">` یا placeholderِ trigger می‌شود، یا اگر انتخاب واقعی است
(مثل «همه») یک sentinel مثل `__all` می‌خواهد که به `undefined` برگردانده شود.

⚠️ **پنل داخل سلول جدول clip می‌شود.** `absolute` داخل یک container با
`overflow-x-auto` بریده می‌شود — **z-index کمکی نمی‌کند**، چون clipping قبل از
stacking اتفاق می‌افتد. راه‌حل: `createPortal` به `document.body` با
`position: fixed`.

### وضعیت صفحه‌ها

تمام (وب + ویندوز + موبایل): `till` `expiry` `budgets` `timesheets` `assets`
`bank` `conflicts` `governance`

`nav-destinations.test.ts` تضمین می‌کند هر مقصد NAV_CONTRACT روی هر سه پلتفرم
فایل صفحه دارد.

## ۷. تله‌های ابزاری که وقت هدر دادند

⚠️ **`python - <<'PY'` در این محیط escapeها را خراب می‌کند.** برای فایل‌های
حاوی regex از ابزار **Write** استفاده کن، نه heredoc. (چند بار پشت سر هم
شکست.)

⚠️ **`cd` بین فراخوانی‌های Bash پایدار نیست.** همیشه از ریشه‌ی مطلق
(`cd /c/Users/hamed/Desktop/hisabche && ...`) شروع کن.

⚠️ **regex روی JSX:** `[^>]*` برای attributeها **کار نمی‌کند** — `=>` در
onChange یک `>` دارد و تگ را زودتر می‌بندد. از `(?<!=)>` یا `[\s\S]*?`
استفاده کن.

⚠️ **گاردی که سورس می‌خواند باید اول کامنت‌ها را حذف کند** — وگرنه کامنتِ
توضیحِ یک رفع، همان رفع را قرمز می‌کند.

⚠️ **dev server وب `packages/ui` را همیشه rebuild نمی‌کند.** اگر تغییری در
مرورگر دیده نشد، اول سرور را restart کن قبل از اینکه دنبال باگ بگردی.

⚠️ **BOM لفظی در سورس** = `no-irregular-whitespace` و commit بسته می‌شود. با
code point چک کن (`charCodeAt(0) === 0xfeff`)، نه با کاراکتر در regex.

## ۸. commit

hook فقط **eslint errors** را مسدود می‌کند (warningها نه). قبل از commit:

```bash
git add -A && git diff --cached --name-only | grep -E '\.(ts|tsx|js|mjs)$' | xargs npx eslint
```

⚠️ lint-staged فایل‌ها را تکه‌تکه می‌دهد و بعد از شکست تکه‌ی اول، **بقیه را
skip می‌کند** — پس ممکن است خطاهای بیشتری پشت خطای اول پنهان باشد.
