## 3. Product Truth & Anti-Hallucination Guardrails

Every prompt strictly complies with verified Hisabche product mechanics:

1. **Allowed Capabilities:**
   - Single invoice triggers 5 simultaneous actions (stock, drawer/bank, customer credit, double-entry ledger, profit).
   - Per-invoice gross profit with fallback to «نامعلوم» when buy cost is missing (unknown is never zero).
