# ۱۰۰ قاعدهٔ طراحی UI و انیمیشن موشنگرافیک — Hisabche Motion Studio

**تاریخ:** 2026-11-18 · **وضعیت:** مرجع الزامی بازسازی `src/ui/**` و `src/components/tactile/**`

این سند جایگزین «وایب قالب سایت» با «زبان بصری موشنگرافیک» است. هر قاعده یا از قراردادهای
خود مخزن (`AGENTS.md`، `production-guardrails.md`، `layout-defect-laws.md`) میآید، یا از رفرنس
منتشرشدهٔ واقعی (بخش ۰). در بازسازی، **هیچ قاعدهای اختیاری نیست**: اگر با کد فعلی تعارض دارد،
کد عوض میشود نه قاعده.

## ۱. بوم و ترکیب (۱–۱۰)

1. **بوم ۵۴۰×۹۶۰ ثابت است، نه responsive web.** طراحی برای قالب ۹:۱۶ عمودی، با مارجین امن ۲۴px از هر لبه. (R5)
2. **ریشهٔ استیج `direction:'ltr'` پین شود**؛ خوشههای فارسی صریحاً `dir="rtl"` بگیرند. وراثت RTL سند پلیر ممنوع است. (R5 / خطای تختهٔ دفتر ۸۸)
3. **مرکزکردن ایمن:** `insetInlineStart:0` + `insetInlineEnd:0` + flex center. الگوی `50% + translateX(-50%)` فقط داخل والد LTR پینشده. (R5)
4. **هیچ خط تقسیمکنندهٔ تزئینی در پسزمینه.** بوم یک سطح واحد است؛ خط فقط وقتیmeaning دارد (خط فاکتور، خط دفتر). (R5 Hard Rule 14)
5. **همپوشانی مطلقاً ممنوع** در فریم hold. فاصلهٔ مراکز دو شکل ≥ نیمعرضها + ۲۴px، یا تفکیک باند y. (R5)
6. **یک نقطهٔ کانونی در هر ثانیه.** اگر دو چیز همزمان حرکت میکنند، یکی باید ساکن باشد. (R1, R5 §5)
7. **حداکثر ۶ واژهٔ غیرزیرنویس روی.frame** در هر لحظه؛ برچسبها ۱–۲ واژه. متن استثناء است، موشن اصل است. (R5 Hard Rule 14)
8. **فریم صفر چیدهشده است.** موشن به داخل قاب آماده میآید، نه از خلأ. (R5 Hard Rule 16)
9. **هیچ push-in / فوکوس / زوم دوربین.** مقیاس استیج همیشه ۱.۰؛ حرکت دوربین فقط panning ترجمهای مجاز است. (R5 بند ۱۱٫۹)
10. **تم تاریک الزامی.** پالت obsidian / dark-neon / midnight-gold / swiss-editorial. تم لایت ممنوع مگر اینکه صحنهٔ کاغذی «ماده» باشد (آنجا کاغذ ماده است، نه تم سایت). (R5 §4.6)

## ۲. تایپوگرافی (۱۱–۲۰)

11. **یک تیتر کینتیک در هر قاب.** بقیهٔ متنها ساکن یا subduedاند. (R2)
12. **کینتیک تایپ رسانه است، نه تزئین.** هر حرکت متن باید بیت روایی داشته باشد. (R1, R2)
13. **stagger حرفها حداکثر ۴۰ms.** بالاتر از آن خواننده منتظر کلمه میماند. (R2)
14. **وزن متغیر فونت را کلیدزنی کن**: کلمه هنگام فرود ضخیمتر شود و آرام بگیرد، نه اینکه از Bold به Regular پرش کند. (R3)
15. **نیمفاصلههای فارسی صحیح** (`می\u200cنویسد`, `به\u200cهم`, `شبانه\u200cی`). فارسی شکسته = REJECT. (R5 §8)
16. **ارقام فقط از `faNumber` با char-map قطعی.** `Intl.NumberFormat('fa-IR')` و `toLocaleString` ممنوع (روی هاست بدون full-ICU رقم لاتین میدهد). (R5 بند ۱۱٫۶)
17. **خط نویسه فارسی never `line-height:1`** مگر رقم تک SLOT. سقف ۱٫۱۵ برای هایلایت کلمه. (R5 Hard Rule 19)
18. **`text-wrap: balance`** برای titleها، `pretty` برای توضیح. orphan تککلمه ممنوع. (R3, R5)
19. **واحد ارزی هاردکد ممنوع.** رقم به شکل خالص `faNumber`؛ کسبوکار تا ۷ ارز دارد. (R5 §4.4)
20. **زیرنویس کلمهبهکلمه تنها با شواهد alignmentreal.** تا زمان ضبط صدا `PROVISIONAL` و `confidence:null` صادق بمان. (R5 Hard Rule 17)

## ۳. رنگ و ماده (۲۱–۳۰)

21. **تک منبع رنگ: `ACCENT` در `art-direction.ts`.** هگز پراکنده در کامپوننتها ممنوع. (R1)
22. **همهٔ رنگها از توکن دربیایند** (`ACCENT[tone].solid/soft/glow`)؛ حتی `stroke` و `fill` SVG. (R5)
23. **یک مادهٔ intentional + یک رسانهٔ متضاد.** کاغذ دستنویس (صحنههای ۱–۳) در برابر دقت دیجیتال (صحنههای ۴–۵). تضاد zelf turn داستان است. (R1)
24. **بافت آنالوگ مشخص، نه فیلتر VHS عمومی.** مرجع واقعی: کاغذ اسکنشده، جوهر ماژیک، نوار پخش قدیمی. (R1)
25. **گرِین لایهٔ ایستا با opacity ≤0.35.** گرِین متحرک یا >0.35 خوانایی را میکشد. (R2)
26. **سایهٔ نرم چندلایه، نه glow بیانتها.** `box-shadow` با opacity کنترلشده؛ neon سقف دارد. (R1, R5 §5)
27. **پالت محدود:** obsidian + ۲ accent + کاغذ. رنگ سوم فقط برای خطای بحرانی. (R1)
28. **هایلایت متن بدون background جعبه.** از وزن/رنگ/زیرخط دستنویس.use کن، نه «card badge» دور کلمه. (R2)
29. **Restraintpective style:** قبل از اضافهکردن افکت بپرس «چه چیزی را میرساند؟»؛ اگر بدونش پیام میماند، اضافه نکن. (R1)
30. **هر.frame یک grade دارد.** رنگ صحنه نباید در میانهٔ.frame عوض شود مگر در turn مشخص. (R1)

## ۴. فیزیک حرکت (۳۱–۴۰)

31. **منحنی پیشفرض: `cubic-bezier(0.16,1,0.3,1)` (Exponential Ease-Out).** Linear ممنوع. (R5 §5)
32. **فنر فقط در چکمارک/تگ/ورود کارت** (`studioSpring`)؛ در هایلایت کلمه فنر ممنوع (جهش میزند). (R5 Hard Rule 19)
33. **انیمیشن فقط `transform` و `opacity`.** خواص layout (`width`,`top`,`margin`) در تایمالاین ممنوع. (R2, R4)
34. **همهٔ انیمیشنها تابع محض `(t)`اند.** scrub-safe، deterministic، بدون `Math.random`، بدون state. (R5)
35. **هیچ `transition: all`.** فقط خواص صریح transition بگیرند. (R2)
36. **زمان ورود ۰.۲–۰.۶s** برای عناصر معمولی؛ ۰.۸s فقط برای قهرمان صحنه. (R5 §5)
37. **Overshoot فنر ≤ ۱٫۰۵ مقیاس** در کارت؛ بالاتر از آن «لاستیکی» بهنظر میرسد. (R5)
38. **خروج به همان نرمی ورود** یا برش با قصد (match-cut)؛ محو ناگهانی بدون دلیل ممنوع. (R1)
39. **سکون هم طراحی است.** holdها بیحرکتند مگر یک tick/echo با intent. (R1 T8)
40. **cadence استاپموشن با `steps()`** وقتی ماده کاغذ/flipbook است؛ نه ease نرم. (R2)

## ۵. ریتم و staggering (۴۱–۵۰)

41. **فاصلهٔ ورود عناصر تکرارشونده ۵۰–۱۲۰ms.** (R5 §5)
42. **سقف ۴۰ms/حرف** در کینتیک تایپ (R2) —با ۵۰–۱۲۰ms/کلمه اشتباه نشود.
43. **هر کات روی بیت صدا صورت میگیرد**؛ کات بیصدا = کات بیقصد. (R1)
44. **آخرین رویداد صوتی هر صحنه ≥1.5s قبل از پایان**؛ پنجرهٔ خروج ۰٫۱۸s بیصدا. (CONTEXT reel-112)
45. **هوک شوک فریم صفر ۰.۰–۰.۷s** قبل از اولین کلمه (VIRAL_HOOKS فرمول ۴). (R5 §3)
46. **تکانهٔ صوتی در ۰.۰ و ۱٫۵s** (sub-drop / تیک مکانیکی / impact). (R5 §3)
47. **هیچ صحنهای بیصدا وارد نشود** —اولین بیت صوتی ≤0.5s محلی. (CONTEXT reel-112)
48. **کاتهای متوالی واژگان ترنزیشن یکسان تکرار نکنند**؛ هر ریل ≥۳ نوع ترنزیشن. (R5 Hard Rule 15)
49. **HOLD بلند فقط ۱–۲ cue** (tick / echo / sync)، نه بستر افکت. (R1, CONTEXT reel-112)
50. **شتاب ریتم intentional است** (مثل rewind ۰٫۸۵→۱٫۳۰→۱٫۵۸)، نه توزیع یکنواخت تصادفی. (CONTEXT reel-112)

## ۶. انتزاع رابط کاربری (۵۱–۶۰)

51. **اسکرینشات خام ممنوع** — UI به وکتور مینیمال و درشت برای موبایل عمودی بازطراحی شود. (R5 §5)
52. **چراغهای ترافیکی، نوار عنوان مرورگر، sidebar آیکونی، «Cloud» pill» = وایب قالب سایت. حذف شوند.** (جایگزین: خط فاکتور، پنل شناور، برش مقیاسشده)
53. **کارت glass bento با border-radius 24px = وایب قالب سایت.** جایگزین: پنل لبهٔ تخت، صفحهٔ کاغذ، یا فرم هندسی. (R1)
54. **نمودار با خطوط گرید محور = وایب داشبورد.** جایگزین: مسیر Bézier تنها، نقاط نشانه، عدد در انتها. (R1)
55. **Toast شناور، cursork مaus، badge دایرهای = UI chrome واقعی، نه موشن.** حذف یا بازمعناشد. (R1)
56. **مختصات داخل موکاپ container-local باشند** + `overflow:'hidden'`؛ پرتاب محتوا به بیرون کادر ممنوع. (R5 بند ۱۱٫۸)
57. **موکاپ فقط قطهای از محصول را نشان دهد** (یک فاکتور، یک ردیف، یک تایید)، نه کل اپلیکیشن. (R5 §5)
58. **عناصر UI وزن بصری متفاوت داشته باشند:** عدد قهرمان > برچسب > خطوط راهنما. (R1)
59. **هر المان UI دلیل روایی داشته باشد** —«چون اپلیکیشن اینطور است» دلیل نیست. (R1)
60. **از data-attribute برای QAاستفاده شود** (`data-ui-camera`, `data-metaphor`)، نه برای تزئین. (R5)

## ۷. نمایش داده و عدد (۶۱–۷۰)

61. **عدد ناشناخته = `null` / «نامعلوم» / «؟؟؟»، هرگز `0`.** (R5 §3)
62. **خطای خواندن ≠ دادهٔ خالی.** `.is()` و branches جداگانه؛ Failed read throw شود. (R5 §3)
63. **هیچ خواندن محدودشده feed نکند عدد تصمیمگیر.** `selectAllPages` / `count:'exact'`. (R5 §3)
64. **جمع پول بین ارزها ممنوع** — گروهبندی بر حسب ارز یا فیلتر تک ارز. (R5 §3)
65. **Number Transform بدون flicker**: عدد معرفی شده continuously بماند و morph کند، نه disappear/reappear. (R5 Hard Rule 1)
66. **ارقام faNumber با char-map قطعی** (تکرار قاعدهٔ ۱۶ چون بیشترین نقض را دارد). (R5 بند ۱۱٫۶)
67. **unit واحد پولی نپذیرد** مگر از books currency سرور. (R5 §3)
68. **مقادیر پول حداقل دو ارز در تستها** تا «بیشتر از.one» واقعاً تست شود. (R5 §6)
69. **نتیجهٔ محاسبه را با دست حساب کن و در کنارش scale assertion بگذار.** (R5 §6)
70. **عدد روی.frame با کلمهٔ همنشیناش بیاید** (مثلاً «پنج سند»)، نه تنها رقم. (R5 §6)

## ۸. کاردستی لمسی (۷۱–۸۰)

71. **کاغذ پارهٔ واقعی: لبهٔ نامنظم + سایهٔ نرم + بافت اسکنشده.** (R1)
72. **جوهر ماژیک: stroke دستنویس با dash-offset، نه خط صاف CSS.** (R1)
73. **حرکت از قواعد ماده پیروی کند:** کاغذ تا/shift میشود، جوهر کشیده میشود، نوار rewind میشود. (R1)
74. **Stop-motion ۱۲/۸fps روی کاغذ** —هدايت flipbook، نه ease نرم. (R2, R1)
75. **تک ماده غالب + تک مادهٔ متضاد** (کاغذ / فولاد / دیجیتال) —سومی اضافه نکن. (R1)
76. **تقلید استیکر هافتون خاکستری / کمیک دستی ممنوع** — persona فینتک جهانی. (R5 بند ۱۱٫۱۰)
77. **همپوشانی لایهها با سایهٔrealistic عمق بدهد**، نه با border رنگی. (R1)
78. **تکهچسب (masking tape) نیمهشفاف با لبهٔ پارهای** —نه نوار سفید صاف. (R1)
79. **بافت grain ایستا زیر کاغذ، نه روی متن.** (R2)
80. **ترک/پارگی فقط در نقطهٔ turn داستان** (پاره شدن گذشته). (R1)

## ۹. صدا و همزمانی (۸۱–۹۰)

81. **SoundKind تنها پالت مجاز**؛ kind اختراع نشود. (R5)
82. **هر کلمهٔ صدادار action دارد و آن action در Actor file کشیده میشود** (AV-Sync §1). (R5)
83. **دو رویداد شنیدنی ≥150ms فاصله** قبل از ضریب؛ نزدیکتر ادغام میشوند. (AV-Sync §3)
84. **`sentenceEnding` صدا ندارد** —hold رویداد نیست. (AV-Sync §2)
85. **لایهبندی صدا: ambient / riser / UI SFX**، جدا از voice. (R1)
86. **زیر گوینده افکتها کم شوند**، not spam. (R1)
87. **انتقال آنالوگ→دیجیتال با صدا هم شنیده شود** (markerScribble → dataFlow). (R1)
88. **صدای بافت، ماده را معرفی کند** (paperRustle, paperTear, clockTick). (R1)
89. **همزمانی میللیثانیهای** با word cueها؛ no `setTimeout` در رندر. (R5)
90. **هیچ صدای «موفقیت» عمومی روی لحظهای که جریان داده است** —دقت صدا = دقت معنا. (R1)

## ۱۰. QA و ضدقالب (۹۱–۱۰۰)

91. **Existing Code First**: قبل از کامپوننت جدید، موجودها جستجو شوند. (R5 / Reference Engine)
92. **DO NOT DESIGN WHAT YOU CAN SOURCE** —ادیتور باش، نه template generator. (R5 §10)
93. **Anti-Repetition:** هیچ دو ریل ساختار صحنه/پترن بصری/توالی یکسان ندهند. (R5 §2)
94. **Creative Collision ≥0.35 شباهت = REJECT** (variety-check). (R5 §9)
95. **قاب ثبت بصری (visual-qa) بعد از هر فیکس دوباره گرفته شود** —«فیکس شد» بدون.frame نو دروغ است. (R5 بند ۱۱٫۷)
96. **tsc 0 · vitest 100% · eslint 0 · build موفق** قبل از اعلام اتمام. (R5 §7)
97. **هیچ `any` / `@ts-ignore` / `eslint-disable` / dead code / unused import.** (R5)
98. **API صادراتی کامپوننتها حفظ شود** —بازسازی ظاهری است، قرارداد مصرفکننده شکسته نمیشود. (این سند)
99. **کامپوننت self-contained باشد:** وابستگی بصری به `.card`/`.mockup-window` در styles.css قطع شود. (این سند)
100.  **صداقت در گزارش:** آنچه اجرا نشد («بیلد»، «رندر»، «forced-alignment») عمداً «اجرا نشد» نوشته شود. (R5 §9٫6)
