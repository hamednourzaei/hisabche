# Capture manifest — the real recordings the reels need

Recordings of the real product live **outside the repository**, in the captures folder
(`HISABCHE_CAPTURES_DIR`, default `~/Videos/hisabche-captures`). A reel that shows the product
cannot export without its file (`blockedBy: 'PRODUCT_CAPTURE'`, before any frame is drawn).

This table is generated from the reels themselves: `node scripts/capture-manifest.mjs --write`.
It is read from each `product-capture` scene — file, product page, scene length, the screen state it
must show. Nothing here is typed by hand, so it cannot disagree with the reels.

How to record: sign in yourself, open the page, record the screen at 1080 px wide or more, name the
file exactly as in the table, put it in the captures folder. Use test data, nothing sensitive. The
recording may be longer than the minimum; it is never shorter.
