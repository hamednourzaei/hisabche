# نقشه مالکیت فایل‌ها برای ایجنت‌های موازی (Multi-Agent Ownership Architecture)

هنگامی که چند ایجنت هوش مصنوعی به صورت موازی برای ارتقا، ساخت ویدیوهای جدید یا نگارش تست‌ها به کار گرفته می‌شوند، تداخل در ویرایش فایل‌ها باعث شکستن بیلد و تعارض در کدهای اصلی می‌شود.
این سند مرزبندی دقیق حقوق ویرایش و دسترسی فایل‌ها را تعیین می‌کند.

---

## ۲. قوانین طلایی عدم تداخل (Collision-Free Protocols)

1. **یک فایل برای یک ریلز جدید (One File Per Batch):**
   - برای اضافه کردن ۵ ویدیوی جدید، هرگز فایل‌های موجود قبلی (`reels-02-10.ts` یا `reels-11-20.ts`) را دوباره بازنویسی نکنید.
   - همیشه یک فایل جدید مجزا (مانند `src/reels/reels-26-30.ts`) ایجاد کرده و آن را در `src/reels/index.ts` اکسپورت کنید.

2. **توسعه افزایشی تست‌ها (Additive Tests Only):**
   - تست‌های موجود در `src/__tests__/motion-engine.test.ts` را ضعیف نکنید؛ صرفاً تعداد ریلزهای مورد انتظار را آپدیت کرده و تست‌های بررسی ویدیوهای جدید را اضافه کنید.

3. **قفل استایل‌های گلوبال (No Drive-by CSS Overwrites):**
   - از اضافه کردن کلاس‌های هم‌نام در `src/styles.css` خودداری کنید؛ استایل‌های اختصاصی هر کامپوننت جدید باید پیشوند مشخص داشته باشند.
