# ماتریس فیزیک حرکت و منحنی‌های سرعت (Motion Physics & Velocity Curves)

حرکت در رابط کاربری SaaS برخلاف انیمیشن‌های فانتزی کارتونی، باید دارای وزن فیزیکی (Physical Mass)، کشش تحلیلی و شتاب ملموس باشد.
حرکت‌های سست، شناور نامشخص، یا خطی (Linear) مطلقاً ممنوع هستند.

## ۱. فنر تحلیلی $O(1)$ (Closed-Form Analytical Spring)

انیمیشن‌های طبیعی باید از حل معادله دیفرانسیل نوسانگر میرا (Damped Harmonic Oscillator) به صورت تحلیلی در زمان ثابت $O(1)$ محاسبه شوند، بدون استفاده از حلقه‌های شبیه‌سازی تکرارشونده (Euler integration):

$$m \frac{d^2 x}{dt^2} + c \frac{dx}{dt} + k x = 0$$

در حالت میرایی بحرانی یا زیربحرانی ($\zeta < 1$):

$$x(t) = 1 - e^{-\zeta \omega_n t} \left(\cos(\omega_d t) + \frac{\zeta}{\sqrt{1 - \zeta^2}} \sin(\omega_d t)\right)$$

که در آن:

- $\omega_n = \sqrt{k/m}$ (فرکانس طبیعی)
- $\zeta = \frac{c}{2\sqrt{km}}$ (نسبت میرایی)
- $\omega_d = \omega_n \sqrt{1 - \zeta^2}$ (فرکانس نوسان میرای زاویه‌ای)

در کد موتور حسابچه، این فرمول در تابع `spring(t)` پیاده‌سازی شده و باید برای ورود کارت‌ها، پاپ‌آپ‌ها و نشانگرها استفاده شود:

```ts
export function spring(t: number, config?: { stiffness?: number; damping?: number }): number
```

## ۲. منحنی‌های سرعت مجاز (Authorized Easing Curves)

| نوع حرکت                                    | فرمول / منحنی                           | کاربرد                                      |
| :------------------------------------------ | :-------------------------------------- | :------------------------------------------ |
| **ورود ناگهانی و توقف نرم (Snap & Settle)** | `easeOutExpo`: $1 - 2^{-10t}$           | باز شدن پنل‌ها، ورود اعداد کلیدی، پاپ‌آپ‌ها |
| **پیش‌بینی و شلیک (Anticipate)**            | $t^2 ((s + 1)t - s)$ با $s \approx 1.7$ | خروج فاکتورهای تکمیل‌شده، شلیک چک به مقصد   |
| **نوسان ملایم فرکانسی (Pulse)**             | $\sin(2\pi f t) \times 0.5 + 0.5$       | نبض نورانی هشدارها، وضعیت آنلاین بودن       |
| **حرکت تدریجی خطوط (Stroke Draw)**          | Smoothstep: $3t^2 - 2t^3$               | رسم نمودارها، خطوط ارتباطی وایرهای انبار    |

## ۳. خطوط قرمز انیمیشن (STRICT BANS)

- ❌ **ممنوعیت انیمیشن خطی (`linear`):** هیچ المنتی (به جز چرخش بی‌پایان اسپینر) حق ندارد با سرعت ثابت حرکت کند. انیمیشن خطی مصنوعی‌ترین و آماتورترین نوع حرکت است.
- ❌ **ممنوعیت انیمیشن ورود ساده `fade-up` برای همه المان‌ها:** ورود باید ترکیبی از تغییر مقیاس (`scale: 0.95 -> 1.0`) و موقعیت همراه با فنر تحلیلی باشد.
- ❌ **ممنوعیت مدت‌زمان طولانی بی‌دلیل:** زمان ورود المان‌های UI نباید بیش از ۴۰۰ تا ۶۰۰ میلی‌ثانیه باشد؛ حرکت کند چشم مخاطب را کلافه می‌کند.
