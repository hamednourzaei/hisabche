# قانون طلایی سلامت حروف فارسی و تایپوگرافی RTL (Persian RTL Typography Rules)

زبان‌های برپایه خط عربی/فارسی برخلاف لاتین، دارای حروف پیوسته (Cursive Ligatures) هستند که توسط موتور شکل‌دهی متن (HarfBuzz / TextShaper) به یکدیگر می‌چسبند.
رعایت نکردن این قوانین تایپوگرافی را مخدوش، غیرحرفه‌ای و زشت می‌کند.

---

## ۱. ممنوعیت قطعی شکستن کلمات به حروف جداگانه (NO Char-by-Char Splitting)

❌ **خطای بحرانی:** انیمیت کردن حروف به صورت تک‌تک (مانند اسپلیت کردن استرینگ با `text.split('')` در فریم‌ورک‌های موشن گرافیک) باعث می‌شود حروف به هم چسبیده، جدا و بریده‌بریده شوند:

- نتیجه خطا: «ح س ا ب چ ه» به‌جای «حسابچه»!

✅ **قانون اجباری:** در زبان فارسی فقط و فقط مجاز به انیمیشن‌های زیر هستید:

1. **انیمیشن کلمه به کلمه (Word-by-Word):** تقسیم جمله با فاصله `text.split(' ')` و ورود هر کلمه کامل با اسپرینگ نرم.
2. **انیمیشن ماسک خطی (Line Mask Wipe):** عبور ماسک مستطیلی نرم از راست به چپ در امتداد خط یا پاراگراف.
3. **انیمیشن هایلایت پیوسته (Kinetic Highlight Sweep):** تغییر رنگ یا نورانی شدن کلمه به کلمه.

---

## ۲. جهت‌گیری درست خط و ایزوله‌سازی متون دوجهته (BiDi Protection)

1. در تمام صحنه‌ها جهت پیش‌فرض ظرف متنی باید راست‌به‌چپ باشد: `direction: rtl; text-align: start;`.
2. کلمات انگلیسی یا اصطلاحات لاتین (مانند `Hisabche`, `SQLite`, `FIFO`, `POS`, `ERP`) باید حتماً در تگ‌های ایزوله یا LTR قرار گیرند:
   ```html
   <span dir="ltr" class="brand-en">Hisabche</span>
   ```
3. پرانتزها، درصدها و علائم ریاضی باید بر اساس ساختار راست‌به‌چپ بسته شوند:
   - درست: `(سود ۲۰٪)`
   - غلط: `%۲۰ سود)`

---

## ۳. ارقام و اعداد جدولی فارسی (Persian Tabular Figures)

1. تمام ارقام نمایش داده شده در داشبوردها، شمارنده‌ها و برچسب‌های زمانی باید از طریق فرمتر فارسی تبدیل شوند:
   ```ts
   export const faNumber = (n: number) => new Intl.NumberFormat('fa-IR').format(Math.round(n))
   ```
2. ارقام پولی یا جدول‌ها باید دارای ویژگی فونت `font-variant-numeric: tabular-nums;` باشند تا هنگام بالا رفتن شمارنده (CountUp)، عرض اعداد پرش نداشته باشد و ستون‌ها نلرزند.

---

## ۴. خواص منطقی استایل‌دهی (Logical RTL CSS Properties)

هرگز از `left`، `right`، `margin-left` یا `padding-right` در استایل‌های CSS استفاده نکنید.
همواره از ویژگی‌های منطقی استاندارد استفاده کنید:

- `inset-inline-start` / `inset-inline-end`
- `margin-inline-start` / `margin-inline-end`
- `padding-inline-start` / `padding-inline-end`
- `border-inline-start` / `border-inline-end`
- `text-align: start` / `text-align: end`
