# کتابچه راهنمای داستان‌گویی محصول‌محور SaaS (Product-Led SaaS Storytelling Playbook)

این سند روح حاکم بر لایه پنجم (Layer 5: The Brain) موتور موشن‌گرافیک حسابچه است.
در استانداردهای جهانی (استرایپ، لینیر، رمپ و اپل)، هدف یک ویدیوی معرفی هرگز تحسینِ «انیمیشن‌های قشنگ» نیست؛ بلکه هدف ایجاد یک **زنجیره روانشناختی خرید** در ذهن صاحب کسب‌وکار است.

---

## ۱. زنجیره روانشناختی ۴ مرحله‌ای مشتری (The 4-Stage Psychological Chain)

هر فیلم تبلیغاتی حسابچه باید مخاطب را از این ۴ ایستگاه حسی عبور دهد:

1. **ایستگاه اول (ثانیه ۰ تا ۳): «لعنتی، این دقیقاً مشکل هر روز منه!»**
   - _شناخت درد آنی (Visceral Pain Recognition)_
   - صاحب کسب‌وکار بلافاصله خود را در صحنه می‌بیند (صف مشتری، قطعی اینترنت، مغایرت انبار، سررسید چک، یا دخل شلوغ بدون سود).

2. **ایستگاه دوم (ثانیه ۳ تا ۱۵): «آها! پس به خاطر همینه که آخر ماه حساب‌هام درنمی‌آد...»**
   - _افشای اصطکاک و هزینه پنهان (Friction & Hidden Cost Exposure)_
   - نشان دادن این که روش سنتی (دفترچه کاغذی، فایل‌های اکسل، حافظه ذهنی) کجا دارد سود یا زمان را هدر می‌دهد.

3. **ایستگاه سوم (ثانیه ۱۵ تا ۴۰): «عجب! حسابچه چقدر ساده و خودکار اینو حل می‌کنه...»**
   - _دموی واقعی محصول و مقایسه قبل و بعد (Real Product Demonstration & Before/After)_
   - اثبات اینکه تنها با ۱ کلیک یا ۱ ثبت فاکتور، تمام پشت‌صحنه (انبار، دفترکل، سود، صندوق) خودکار تنظیم می‌شود.

4. **ایستگاه چهارم (ثانیه ۴۰ تا ۵۹): «حالا دقیقاً می‌دونم پول و جنسم کجاست. بذار امتحانش کنم.»**
   - _پاداش احساسی، آرامش خاطر و اقدام فوری (Outcome, Emotional Payoff & Immediate CTA)_
   - احساس تسلط و کنترل بر کسب‌وکار و دعوت روشن به اقدام (شروع رایگان در `hisabche.com`).

---

## ۲. ماتریس ۹ مرحله‌ای سناریونویسی SaaS (The 9-Step Story Matrix)

قبل از کدنویسی هر ریلز، این جدول باید به صورت شیء `storyMatrix` تعریف شود:

```ts
export interface SaaSStoryMatrix {
  /** 1. مخاطب دقیق و صنف کاری */
  targetCustomer:
    'retail-shopkeeper' | 'wholesaler' | 'workshop-producer' | 'services' | 'accountant'
  /** 2. دغدغه و اضطراب روزمره به زبان بازار */
  customerPain: string
  /** 3. روش سنتی که الان انجام می‌دهند */
  oldWorkflow: string
  /** 4. نقطه‌ای که روش سنتی می‌شکند و پول هدر می‌رود */
  friction: string
  /** 5. عمل واقعی و ملموس درون حسابچه */
  hisabcheAction: string
  /** 6. پردازش‌های خودکار پشت صحنه */
  automatedResult: string
  /** 7. دستاورد عملیاتی و مالی قابل لمس */
  businessOutcome: string
  /** 8. حس تسلط و پایان اضطراب */
  emotionalPayoff: string
  /** 9. دعوت به اقدام کم‌هزینه و فوری */
  cta: string
  /** انتخاب دقیق ۵ تا ۶ اپراتور موشن متناسب با این داستان */
  selectedOperators: string[]
}
```

## ۳. تحلیل نمونه: ویدیوی شماره ۲۳ (فروش ۵۰ میلیونی در برابر سود خالص واقعی)

- **مخاطب (`targetCustomer`):** کاسب و فروشگاه‌دار پرتراکنش.
- **درد روزمره (`customerPain`):** دخل شلوغه و امروز ۵۰ میلیون فروش رفته، اما آخر ماه نقدینگی برای خرید مجدد کم می‌آید.
- **روش سنتی (`oldWorkflow`):** ثبت فروش با جمع زدن ماشین‌حساب یا تصور ذهنی اینکه «۲۰ درصد از هرچی فروختم سوده!».
- **اصطکاک (`friction`):** کالاهایی که با قیمت‌های خرید متفاوت (خرید قدیم ارزان‌تر، خرید جدید گران‌تر) وارد شده بودند با بهای میانگین اشتباه حساب شدند؛ به علاوه تخفیف‌ها و نسیه‌ها کسر نشدند.
- **عمل حسابچه (`hisabcheAction`):** ثبت فاکتور با محاسبه اتوماتیک لایه‌ای فایفو (FIFO Costing) و تفکیک بلادرنگ بهای خرید از سود ناخالص.
- **نتیجه خودکار (`automatedResult`):** کسر لحظه‌ای هزینه و بهای خرید از تک‌تک اقلام و محاسبه دقیق سود خالص.
- **دستاورد مالی (`businessOutcome`):** دانستن دقیق سود خالص هر فاکتور تا ریال آخر در همان لحظه فروش.
- **پاداش حسی (`emotionalPayoff`):** پایان توهم فروش بالا؛ آرامش خاطر و کنترل صددرصدی روی نقدینگی واقعی جیب.
- **دعوت به اقدام (`cta`):** شروع رایگان در `hisabche.com`.
- **اپراتورهای منتخب (۵ مورد):**
  1. `Radial Clock Dial & Progress Ring` (گذر روز کاری از صبح تا شب)
  2. `X-Ray Profit Scanner` (افشای معمای سود زیر ظاهر پرپول دخل)
  3. `Profit Waterfall Drain` (ریزش لایه‌به‌لایه بهای خرید و هزینه‌ها از ۵۰ میلیون فروش)
  4. `Camera Portal Pass-Through` (ورود به قلب نرم‌افزار حسابچه)
  5. `Isometric UI Layer Explosion` (تفکیک خودکار لایه‌های انبار و سود)
