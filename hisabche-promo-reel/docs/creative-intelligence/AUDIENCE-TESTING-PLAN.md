# Audience Testing & Empirical Performance Plan

## Rationale

Code inspection and motion design analysis prove technical fidelity, but **actual conversion, retention, and viewer engagement cannot be established without live audience experiments**.

## Experiment 1: The 3-Second Hook Dilemma (Problem vs Question)

- **Hypothesis:** Opening with an acute financial loss warning («کسری انبار») produces a 25% higher 3-second hold rate than an interrogative question.
- **Target Audience:** Independent retail and wholesale business owners (25–54 yrs, Iran/Afghanistan/Tajikistan).
- **Control:** Reel 05 standard question hook.
- **Variant A:** High-contrast binary dilemma card (Frame-0 arrest).
- **Primary Metric:** 3-Second View-Through Rate (VTR).
- **Decision Rule:** Adopt Variant A across topic cluster if VTR exceeds Control by > 15% with 95% confidence.
