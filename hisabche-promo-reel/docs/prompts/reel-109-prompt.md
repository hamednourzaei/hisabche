## ۱. راهنمای گوینده (Voiceover Direction)

- **لحن:** آرامِ مطمئن، همان طوری که یک کارکشتهٔ بازار جُمالیات را برای بچهٔ شاگردی‌اش توضیح می‌دهد — نه تبلیغاتی، نه هیجانی.
- **ریتم:** جمله‌ها کوتاه‌اند؛ بعد از «؛» یک مکث نفس کوتاه (حدود ۰٫۳ ثانیه). سراسر ۴۲ ثانیه با یک نفس راحت خوانده می‌شود.
- **کلمات تاکیدی:** «کدوم سمت»، «نمی‌خونن»، «یکجا»، «پنج سند»، «هم‌زمان» — روی این‌ها کمی سنگین‌تر بنشینید.
- **سندهای خطاهای رایج:** خواندن «اَCESSل» غلط است؛ «اکسل» بنویسید. «نمی‌خونن» بومی است — طبیعی بخوانید، نه رسمی «نمی‌خوانند».

## ۳. قواعد ضبط و همگام‌سازی

- ارقام همه با `faNumber` — رقم لاتین در هیچ فریمی استفاده نشده.
- هر واژه‌ای که `sound` می‌گیرد `action` دارد و موتور صحنه آن را بخواند (قاعدهٔ سخت ۱۳). اسکریپ این ریل plan واژه ندارد (هم‌ریت又说 سبک صحنه‌های ۱۰۰ به بعد)؛ صداهای صحنه با `cues` همان `Cue[]` گره خورده.
- مهرها فقط در پنجرهٔ اوج ۱٫۲ ثانیه کامل opaque می‌مانند؛ خارج حذف نمی‌شوند.
- صرفاً این‌ها ادعا می‌شوند که واقعاً محصول می‌سازد: پنج کارِ فاکتور (انبار/صندوق/دفتر/طلب/سود) — موکب `README.md §3` کتابخانهٔ پرامپت.

## ۴. گام بعدی صداگذار

1. ضبط فایل صوتی با خطوط جدول ۶گانه (یک فایل پیوسته، پیشنهادی ~۴۱ ثانیه خالص).
2. پس از ضبط: `node scripts/align-voiceover.mjs 109` برای ساختن `src/reels/alignments/reel-109-alignment.json`.
3. سپس `node scripts/check-av-sync.mjs 109 --mix` تا گیت صوتی تصویری (±۴۵ms) بدرقهٔ خروجی شود.
4. تایید نهایی: `npm run build` و `npm run visual-qa`.
