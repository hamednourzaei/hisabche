# ریلز ۱۱۱ — درمان نرمافزارهای سطحی — چرا حسابچه؟

> **فایل تعریف:** `src/reels/reel-111-shallow-software.ts` · **موتور صحنه:** `src/scenes/shallow-software.tsx`
> **مدت:** ۴۲٫۰ ثانیه · **تم:** `dark-neon` · **مکانیسم:** تشخیص چهار نقص نرمافزار سطحی و درمان آفلایناول
> **یادداشت:** این سند بر اساس تعریف موجود ریل بازسازی شده است (همگامی صدا هنوز موقّت است).

## ۱. ایده

کاسب از نرمافزارهای حسابداری سطحی خسته است: با قطعی اینترنت قفل میکند، فقط تحت وب است و روی گوشی نصب نمیشود،
انعطافی ندارد و زیر فشار واقعی بازار میشکند. حسابچه درمان است: موتور آفلایناول، نصب بومی واقعی
(اندروید، ویندوز، وب) و انعطاف عمیق متناسب با کسبوکار.

## ۲. راهنمای گوینده

- لحن: صریح و کمی تلخ در سه صحنهٔ اول؛ آرام و قطعی از صحنهٔ سوم.
- تأکید: «قطعی اینترنت»، «قفل میکنه»، «آفلایناوله»، «روی گوشی»، «قدِ کارِ تو».
- مکث کوتاه بعد از «؛»؛ جملهها نفسپذیر.

## ۴. صداقت محصول

ادعاها محدود به قابلیتهای مستند حسابچهاند: کارکرد آفلاین محلی، همگامسازی پس از اتصال مجدد،
نصب بومی روی چند دستگاه و انعطاف ماژولار. هیچ ادعای مالیاتی/بانکی جعلی وجود ندارد.

## ۵. گام بعدی صداگذار

1. ضبط فایل پیوسته (≈۴۱ ثانیه خالص).
2. `node scripts/align-voiceover.mjs 111` → `src/reels/alignments/reel-111-alignment.json`.
3. `node scripts/check-av-sync.mjs 111 --mix` (گیت ±۴۵ms).
4. `npm run visual-qa` و سپس `npm run build`.
