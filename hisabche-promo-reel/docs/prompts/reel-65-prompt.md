# Reel #65 — «سه صندلی پر؛ اما شب فقط یک عدد می‌بینی»

> **سند راهبردی و راهنمای صداگذاری.** هیچ‌کدام از این برچسب‌ها نباید روی بوم ۹:۱۶ ظاهر شوند.
> منبع مکانیک: کتابخانه پرامپت `hp-018` (تکنیک بستن شیفت و مغایرت‌گیری صندوق) که برای سالن زیبایی بازطراحی شده است.

---

## ۱. چرا این ریل

- **شخصیت:** کاسب خدماتی/خرده‌فروش (`retail-shopkeeper`) — آرایشگری با سه صندلی.
- **مکانیسم خلاقانه:** `station-wall-profit-attribution` — دیوار صندلی‌ها؛ هر خدمت روی صندلی خودش می‌نشیند.
- **پالت:** `obsidian-cinematic` با لهجهی رز/کهربایی و سبز سود — عمداً متفاوت از طلایی ۶۳ و سوئیسی ۶۴.
- **قلاب:** `uncomfortable-discovery` — فروش روز را می‌بینی، سودِ هر صندلی را نه.
- **تفاوت با ریل‌های اخیر:** ۶۲ پرینتر حرارتی، ۶۳ مظنه و اجرت ساخت، ۶۴ بهای تمام‌شده کارگاه. اینجا «بستن شیفت و سود هر ایستگاه» است.

## ۵. قوانین بصری الزامی

1. **فریم صفر چیده است:** صندلی‌ها و کارت‌ها از ثانیهٔ ۰ روی بوم هستند؛ موشن به داخل قاب آماده می‌آید.
2. **متن روی بوم فقط کارکردی:** فروش · سود · دفتر · ماشین‌حساب · محصولات · خدمت · مصرفی · رقم صندلی‌ها. جملهٔ گوینده هرگز روی بوم تکرار نمی‌شود؛ سقف ۶ واژهٔ غیرزیرنویس رعایت شده (بیشترین حالت: ۵ واژه در صحنهٔ ۲).
3. **پایداری متن:** هر برچسبی که ظاهر شد تا پایان صحنه می‌ماند؛ چیپ‌های مصرفی جمع نمی‌شوند و نمی‌روند.
4. **بدون خط جداکننده:** نه خط افقی، نه مرز اسپلیت — یک بوم واحد.
5. **اعداد یک‌طرفه بالا می‌روند** (بدون پرش و چشمک)؛ صندلی ۲ از ۰ به −۶۸۰٬۰۰۰ پایین می‌آید و قرمز می‌ماند.
6. **زیرنویس:** فقط همین فایل صدا همگام می‌شود؛ هایلایت نرم (بدون فنر جهشی) — Hard Rule 19.

## ۶. بلعیدن صدا (Audio ingestion)

```bash
node scripts/place-voiceover.mjs 65      # چیدن فایل و ساخت audio/reel-65-vo.wav
node scripts/align-voiceover.mjs 65      # استخراج فرازهای صوتی
node scripts/check-av-sync.mjs 65 --mix  # دروازهٔ همگامی: هر ضربه باید در ±۴۵ms بنشیند
```

تا وقتی forced-alignment واقعی اجرا نشده، وضعیت صادقانه همان `PROVISIONAL_CADENCE_MODEL_ACTIVE` با `confidence: null` است. اگر فایل صوتی ساخته شد ولی همگام‌سازی واژه‌ای نشد، وضعیت به `AUDIO_DETECTED_NOT_WORD_ALIGNED` ارتقا می‌یابد — نه بیشتر.
